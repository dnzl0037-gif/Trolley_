# Reference notes used for Trolley

## Uploaded visual references

The supplied Trolley cart icon is used as the site logo, favicon and brand mark. The supplied editorial-style security slides informed the use of clear visual hierarchy, warm neutral surfaces, bold black typography, orange emphasis, compact comparison cards and explicit consent/age/subscription disclosures.

## Uploaded video references

The supplied videos were reviewed via representative frames. They reinforce a backend-first approach: validate inputs at trusted endpoints, enforce authorization in the database, avoid exposing secrets, keep private records private, and test generated code rather than trusting it because it compiles or looks complete. They are reference material only and are not bundled into the application.

## Product interpretation

The owner selected Option A: a services marketplace. Trolley is therefore not a retail product store despite the shopping-cart logo. It connects customers with service professionals, with Zimbabwe as the initial market and international-ready country/currency fields.
