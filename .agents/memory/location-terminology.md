name: Location terminology
description: User-confirmed meaning of Region in Trolley's location pickers.
---

The user confirmed that the location picker's “Region” means continents such
as Africa, not provinces or states.

**Why:** The user explicitly selected “Continents such as Africa” when asked.

**How to apply:** Use continent → country choices in location controls. Do not
reinterpret the existing database province/state field as a continent.
